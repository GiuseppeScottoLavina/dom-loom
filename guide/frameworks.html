DomLoom guide

Frameworks

<loom-stage> is a custom element, so it works in any framework. Two things need care. A transition keeps a picture of the page before your update, so the update must be in the DOM when its callback returns. And DomLoom changes the DOM of a sorted table or a removed chip only when nobody else owns it: in a framework, cancel loom-sort and loom-remove and change your state instead, inside a transition or a discard.

The examples on this page are code only: they need a build step for JSX and single-file components.

React

dom-loom/react has the LoomStage component and hooks: useLoomTransition(ref) and useLoomDiscard(ref) run your state update and flush it inside the cut, and useLoomEvent(ref, type, handler) listens to DomLoom's events. Here React owns the rows, so the component cancels DomLoom's sort and sorts its state, while the rows fly: 

        import { useRef, useState } from 'react';
        import { LoomStage, useLoomEvent, useLoomTransition } from 'dom-loom/react';
        import 'dom-loom/style.css';
        import 'dom-loom/table';

        const PLAYERS = [['Ivy', 12], ['Bram', 31], ['Osei', 7]];

        export function Roster() {
          const stage = useRef(null);
          const [players, setPlayers] = useState(PLAYERS);
          const [sort, setSort] = useState(null);
          const transition = useLoomTransition(stage);

          useLoomEvent(stage, 'loom-sort', (event) => {
            event.preventDefault();
            const { column, direction } = event.detail;
            const sign = direction === 'ascending' ? 1 : -1;
            const rows = [...stage.current.querySelectorAll('tbody tr')]; // before the update
            transition(() => {
              setSort({ column, direction });
              setPlayers((list) => [...list].sort((a, b) => (a[column] > b[column] ? sign : a[column] < b[column] ? -sign : 0)));
            }, { morph: rows, cut: false });
          });

          return (
            <LoomStage ref={stage} sound>
              <table sortable="">
                <thead>
                  <tr>
                    <th aria-sort={sort?.column === 0 ? sort.direction : undefined}>Player</th>
                    <th aria-sort={sort?.column === 1 ? sort.direction : undefined}>Level</th>
                  </tr>
                </thead>
                <tbody>
                  {players.map(([name, level]) => <tr key={name}><td>{name}</td><td>{level}</td></tr>)}
                </tbody>
              </table>
            </LoomStage>
          );
        }

A removal works the same way: cancel loom-remove, then call discard(event.target, () => setItems(…)) from useLoomDiscard; pass { exit: 'shatter' } as a third argument for shards. Write DomLoom's attributes as strings in JSX (sortable="", hold="900ms"); the types in dom-loom/react declare them. LoomStage also takes onReady and onFallback.

Vue

Tell Vue that <loom-stage> is a custom element: with app.use(DomLoom) for templates compiled at runtime, or with isCustomElement in the compiler options for single-file components. useLoomStage(ref) gives transition and discard, which wait for Vue's next tick inside the cut. 

        // vite.config.js
        import vue from '@vitejs/plugin-vue';
        import { isCustomElement } from 'dom-loom/vue';

        export default { plugins: [vue({ template: { compilerOptions: { isCustomElement } } })] };
      
        <script setup>
        import { ref } from 'vue';
        import { useLoomStage } from 'dom-loom/vue';
        import 'dom-loom/core';
        import 'dom-loom/style.css';

        const stage = ref(null);
        const boarding = ref(false);
        const { transition } = useLoomStage(stage);
        function changeStatus() {
          return transition(() => { boarding.value = !boarding.value; });
        }
        </script>

        <template>
          <loom-stage ref="stage">
            <section>
              <h2 v-if="boarding" data-morph="flight">Boarding now</h2>
              <p v-else data-morph="flight">Awaiting boarding</p>
              <button type="button" @click="changeStatus">Change boarding status</button>
            </section>
          </loom-stage>
        </template>

For a state-owned removal, listen with @loom-remove.prevent and call discard(item, update).

Svelte, Solid, Angular

Use the element directly (Angular needs CUSTOM_ELEMENTS_SCHEMA), and make the transition's callback wait for the framework to commit its DOM before it returns, as Svelte's tick() does: 

        import { tick } from 'svelte';

        await stage.transition(async () => {
          showReceipt = true;
          await tick();
        });

With server rendering, let the stage enhance the content on the client, after hydration: the stage moves its content into a source wrapper when it connects. TypeScript types ship with the package.
